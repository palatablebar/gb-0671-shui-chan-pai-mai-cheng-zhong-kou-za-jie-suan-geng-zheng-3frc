# 数据定义

票号与原始编号均为字符串，保留前导零。称重支持 kg、公斤与 t，统一为 kg，单价为 CNY/kg。
毛重与皮重按票号和版本配对，品类、单价、扣杂率与更正目标必须一致。计价重量=(毛重−皮重)×(1−扣杂率)，先量化到0.001kg，再乘单价，金额四舍五入到0.01CNY。
每票第一版不填写 replaces。后续版本只能替代当前生效版，分支或缺基版整票阻断结算。已支付额为各版本中最大累计已付值，待付=最终应付−累计已付；负待付表示待收回。
同编号同原值仅计一次；同编号不同原值全部隔离。空文件、全空行和仅表头分别报错。原始输入计数包括空行及重复表头，对账会分别解释。
归档封存保存逐版证据、隔离原因和运行摘要，非支付执行系统。数据使用虚构编号，不连接实际支付渠道。

## 批次与源包

批次号是日结的唯一单位；同一批次下可以有多个源包，但只有一个采用版、最多一个封存版。
运行标识 sha256 = 原始字节 + 上下文 + 规则版本，因此同一补发重试得到同一运行、不再新增结算记录。

| 字段 | 含义 |
|---|---|
| package_id | 批次内源包编号，由批次号与源包摘要确定；重发同内容不新增 |
| confirmed | 源包内容已由结算员确认；未确认的补发包不允许切换，也不允许封存 |
| rejected | 已退回的候选源包；证据保留，但不再参与封存门槛 |
| adopted_run_id | 当前采用版运行；切换成功才改变，切换失败保持旧值 |
| sealed_run_id / seal | 唯一封存版与其证据摘要；重试封存同一采用版返回同一结果 |

比对口径：

- 变化票：两版都能结算，但影响结算的字段（版本、品类、毛重、皮重、净重、计价重、单价、扣杂率、已付、应付、待付、替代版本）至少一项不同。
- 修复票：采用版该票被隔离或版本冲突，补发包能形成唯一生效记录；属合法变化，需逐票可见。
- 无法对应：只有一版有该票，或采用版能结算而补发包不能。存在时暂缓切换与封存。
- 两版都不能结算的票记为未结算票，不阻断。

封存门槛：采用版可归档；无未确认补发包；无已确认但尚未采用的差异补发包（需先采用或退回）；无无法对应的票。
